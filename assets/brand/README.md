# sdrtrunk brand assets

The mark: one radio signal comes in from the left and splits into three channels at the node. A trunking control
channel hands calls off to traffic channels the same way. It also reads as a tree trunk.

| File | Use |
|---|---|
| `sdrtrunk-icon.svg` | Master icon (vector). Edit this one, then regenerate the PNGs. |
| `png/sdrtrunk-icon-{16..1024}.png` | App and window icons (transparent background). |
| `sdrtrunk.ico` | Windows icon (16 to 256 px). |
| `sdrtrunk.icns` | macOS icon. |
| `sdrtrunk-splash.png`, `sdrtrunk-splash@2x.png` | Application splash screen (640x360 and 1280x720). |
| `sdrtrunk-social.png` | 1200x630 link-preview image for the website. |
| `src/*.html` | Sources for the splash and social images, rendered with headless Chrome. |

Colors: cyan `#22d3ee`, mint `#2ee6a6`, green `#7cf05a` on navy `#08121d`.
Fonts: Space Grotesk (wordmark, headings), Inter (body), JetBrains Mono (labels).
